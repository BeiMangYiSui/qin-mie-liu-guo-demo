4. 功能模块说明

4.1 章节剧情（src/game/story.ts + src/sections/StoryScene.tsx）
    - 玩法：玩家按场景顺序阅读剧情，每行剧情包含
      类型（旁白/对白/内心/演出/字幕）、说话人、文本。
    - 行为：自动翻页、点击推进、关键选项触发分支。
    - 数据：scene.id、scene.lines、scene.choices、scene.continuation。
4.2 分支选择（src/ui/C7ChoicePanel.tsx 等）
    - 在 C7 三择其一、C1 三证合勘、C4 战术选择等节点提供选项。
    - 选择结果写入 StoryFlags（如 c4_tactic、c7_choice）。
    - 后续场景与战斗配置根据 flag 调整。
4.3 回合制战斗（src/game/battle.ts + src/sections/BattleScene.tsx）
    - 玩家控制三人小队，按敌方行动意图选择行动。
    - 行动类型：攻击、救援、打断、坚守、夺证、撤离。
    - 行动会产生飘字、命中特效、突进、抖动等视觉反馈。
    - 失败/胜利条件由 BattleConfig 配置：
      mode: annihilate / defend / boss，winLog、loseLog、
      回合上限、不同初始敌方等。
4.4 教学战斗（src/game/tutorial.ts + src/sections/TutorialBattleScene.tsx）
    - 序章郑地伏杀，三项目标数值上不可全成（设计宣言锁定）。
    - 帮助玩家熟悉行动分配、AP 成本、打断与救援规则。
4.5 火场救援（src/ui/FireRescue.tsx）
    - 计时与选项交互，影响 c7_saved_registers 集合。
4.6 追截战斗（src/ui/PursuitIntercept.tsx）
    - 计时与命中交互，影响 c7_troops_intercepted。
4.7 防守撤离（src/game/defenseBattle.ts + src/ui/DefenseBattlePanel.tsx）
    - 护送北芒率疫营撤离，撤离成功/失败写入 evac_survival。
4.8 章末结算（src/ui/SettlePanel.tsx）
    - 汇总人员存活、任务目标、关键选择与史乘参考。
4.9 史乘卡（src/ui/ShichengPage.tsx + src/ui/shichengData.ts）
    - 4 张历史对照卡；C2 通过解锁前两张，C8 章末后解锁后两张。
4.10 存档系统（src/game/save.ts + src/components/SaveLoadModal.tsx）
    - 3 个手动存档槽位 + 战前自动存档 + 战败回卷。
    - 存档数据包含 saveVersion、slot、stage、flags、savedAt。
    - checkSaveCompatibility 检测 legacy / compatible / future / invalid。
    - normalizeStoryFlags 过滤非标量值、限定 c7_saved_registers 取值集合。
4.11 音频系统（src/game/audio.ts）
    - 场景 BGM：ambush / farm / court 三轨，标题/战前/战后按 stage 切换。
    - 角色配音：voice/manifest.json 索引 + 文本匹配。
    - 音效：sfx/*.mp3，分 environment / effect 两个通道。
    - 移动端首次用户交互解锁音频。

7. 战斗规则

7.1 行动规则
    - 敌方行动意图在回合开始时公开，玩家根据意图选择行动。
    - 行动消耗 AP；回合结束自动结算玩家已选行动。
    - 击中/打断/救援/坚守会产生飘字、命中特效、突进、抖动。
7.2 胜利条件
    - annihilate：清除所有敌方。
    - defend：在限定回合内守住目标。
    - boss：达成特定剧情目标（夺控/护送/撤离）。
7.3 失败条件
    - 关键人员血量归零、回合上限耗尽、未达成剧情目标。
7.4 教学战设计（src/game/tutorial.ts）
    - 总 AP 8；救孟甲 3AP、守谷口 3AP、三次打断夺明卷 3AP，
      9 > 8，锁死三项目标不可全成。
7.5 战前自动存档
    - armBattleSave 在战前 stage 写入 autosave：qmlg:autosave:current。
    - 战败时 rollbackToBattleSave 读取并恢复 stage、flags。
7.6 战斗配置
    - BattleConfig.mode：annihilate / defend / boss
    - BattleConfig.winLog / loseLog：触发胜利/失败的剧情文案
    - BattleConfig.turnLimit：回合上限（用于 defend）
    - BattleConfig.enemies：敌方初始单位与阵营
7.7 行动类型枚举
    - attack：攻击，对敌方单体造成伤害
    - interrupt：打断，阻断敌方当前意图
    - rescue：救援，回复友方血量或解除控制
    - hold：坚守，本回合不主动攻击，提高防御
    - seize：夺证，剧情类目标（夺明卷、夺户籍）
    - evacuate：撤离，护送目标至回合结束

8. 存档与版本兼容

8.1 数据格式
    { saveVersion: 2, slot: number, stage: Stage, flags: StoryFlags, savedAt: number }
8.2 槽位
    - 手动槽位：qmlg:save:0、qmlg:save:1、qmlg:save:2。
    - 自动存档：qmlg:autosave:current。
8.3 兼容性
    - saveVersion < CURRENT_SAVE_VERSION：legacy，
      UI 提示旧存档不兼容，提供重置重开。
    - saveVersion > CURRENT_SAVE_VERSION：future，禁止覆盖。
    - saveVersion === 2：compatible，正常读取。
8.4 flag 规范化
    - 仅允许 boolean / string / number / null / 字符串数组。
    - c7_saved_registers 限制为拼音 id 集合，
      去重后最多保留 3 项。
8.5 存档结构
    - saveVersion：存档版本号，递增保护旧存档
    - slot：槽位编号（0~2 或 autosave）
    - stage：当前剧情阶段（Stage 枚举）
    - flags：本次剧情已解锁的标记
    - savedAt：保存时间戳（毫秒）
8.6 兼容性矩阵
    - legacy → latest：UI 提示、禁止覆盖、提供重置重开
    - compatible → latest：直接读取
    - future → latest：禁止读取、禁止覆盖
    - invalid：JSON 解析失败、字段缺失，丢弃并不写入

    - 首次用户交互后通过 unlockAudio 解锁 BGM/配音/环境音。

15. 详细设计 - 战斗引擎（src/game/battle.ts）

15.1 模块职责
    - 实现回合制战斗核心循环：

    - 维护 BattleState：双方单位、AP、回合数、行动意图。
    - 输出 BattleEvent 流：伤害、命中特效、飘字、判定结果。
15.2 关键数据结构
    - BattleUnit：id、side、name、hp、maxHp、ap、status
    - BattleIntent：unit、action、target
    - BattleConfig：mode、turnLimit、enemies、winLog、loseLog
    - BattleState：units、intent、turn、log、status
    - BattleEvent：type、source、target、payload
15.3 核心函数
    - initBattle(config): 初始化 BattleState
    - declareIntent(unit, action, target): 公开敌方意图
    - chooseAction(unit, action, target): 玩家选行动
    - resolveTurn(): 结算本回合已选行动
    - checkBattleEnd(state): 判定胜负并返回 BattleResult

24. 详细设计 - 关键算法（战斗回合）

24.1 回合循环伪代码
    while battle.status === ongoing:
      declareIntent(enemyUnits)        # 公开意图
      for player in playerUnits:
        action = await chooseAction(player)
        if action and ap>=action.cost:
          player.ap -= action.cost
          enqueue(player, action)
      resolveTurn(state)              # 结算行动
      checkBattleEnd(state)           # 判定胜负
24.2 行动结算顺序
    - 按速度（speed）排序，速度相同按阵营顺序
    - 同一行动单位依次执行 interrupt / attack / rescue / hold
    - 命中后产生 BattleEvent，触发 BattleEffects
24.3 命中计算
    - 命中率 = base + (attacker.skill - defender.dexterity) * 0.05
    - 伤害 = attack - defense + 随机抖动（±10%）
    - 打断：interrupt 命中则取消敌方意图
    - 救援：rescue 命中则回复目标 hp = caster.healPower
24.4 数值边界
    - hp ≤ 0 视为死亡
    - ap < 0 强制归零
    - 伤害 ≤ 0 视为 1（防止溢出）
24.5 胜负判定
    - mode=annihilate：所有 enemy hp ≤ 0
    - mode=defend：turn > turnLimit 或目标单位 hp ≤ 0
    - mode=boss：所有 objectives 完成
24.6 战斗回滚
    - 战败时 rollbackToBattleSave()
    - 恢复 stage、flags
    - 战前自动存档保留
24.7 教学战锁定
    - 总 AP 8，三个目标共需 9 AP
    - 数值上锁死不可全成
    - 设计意图：在练习关给玩家体验代价
24.8 单元测试
    - 意图公开后玩家可正常选择
    - AP 不足时拒绝执行
    - 战斗失败时正确触发 loseLog

25. 详细设计 - 关键算法（存档兼容）

25.1 兼容性判定
    function checkSaveCompatibility(payload):
      if (!payload || typeof payload !== object) return invalid
      if (typeof payload.saveVersion !== number) return invalid
      if (payload.saveVersion < CURRENT_SAVE_VERSION) return legacy
      if (payload.saveVersion > CURRENT_SAVE_VERSION) return future
      return compatible
25.2 写入策略
    - legacy：UI 提示旧存档不兼容，提供重置重开，禁止覆盖
    - compatible：直接写入
    - future：禁止写入
    - invalid：丢弃并不写入
25.3 flag 规范化
    function normalizeStoryFlags(flags):
      const out = {}
      for (const key in flags):
        v = flags[key]
        if (v is boolean | number | string | null):
          out[key] = v
        else if (Array.isArray(v) && v.every(isString)):
          out[key] = [...new Set(v)]
          if (key === c7_saved_registers):
            out[key] = out[key].slice(0, 3)
      return out
25.4 槽位管理
    - 手动槽位：qmlg:save:0、qmlg:save:1、qmlg:save:2
    - 自动存档：qmlg:autosave:current
    - 战前自动存档：armBattleSave(stage, flags)
    - 战败回卷：rollbackToBattleSave()
25.5 异常处理
    - JSON.parse 失败：视为 invalid
    - localStorage 不可用：降级到内存存储
    - 槽位被占用：UI 提示是否覆盖
