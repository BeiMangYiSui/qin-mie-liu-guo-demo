# 微信小游戏账号注册与后台管理操作手册

> 适用：个人开发者
> 流程更新：2026-08-05
> 对应项目：《秦灭六国》

---

## 0. 必读：两套账号的区别

| 账号 | 入口 | 用途 | 适用场景 |
|---|---|---|---|
| 公众号 | `mp.weixin.qq.com` | 推送文章、做内容 | 现有"北邙一穗"就是这个 |
| 小程序 | `mp.weixin.qq.com` | 跑小应用、H5 页面 | — |
| **小游戏** | `mp.weixin.qq.com` | **跑游戏代码、上线发布** | **你要注册的** |

**同一个 mp.weixin.qq.com 网址，但账号类型相互独立**，不能共用。

## 1. 注册前准备清单

下面这些东西**先全部准备好**，注册过程非常快，不准备好会卡住。

### 1.1 个人必填信息

| 信息 | 谁提供 | 用途 |
|---|---|---|
| 真实姓名 | 你本人 | 软著著作权人、平台主体、版权承诺书 — 三个地方必须完全一致 |
| 身份证号（18 位） | 你本人 | 实名认证 |
| 身份证正反面照片 | 你本人 | 实名认证 |
| 实名手机号 | 你本人 | 接收验证码、短信核验 |
| 常用邮箱 | 你本人 | 接收注册邮件、通知 |

### 1.2 新邮箱（必须新建）

- **不能是注册过任何微信公众平台账号（公众号、小程序、小游戏）的邮箱**
- 建议新建一个专门用于"`秦灭六国`项目"的邮箱
- 推荐：163、Gmail、Outlook、QQ 邮箱
- 推荐命名：`qinmieliu@163.com`、`qinmieliu_game@outlook.com` 等

### 1.3 微信本身已实名

- 你的微信账号必须先完成实名认证
- 如果还没实名：打开微信 → 我 → 服务 → 钱包 → 身份信息 → 实名认证

### 1.4 微信绑定手机号

- 你注册小游戏账号时填的"管理员手机号"最好和微信绑定的手机号一致
- 否则后续人脸识别、扫码确认可能失败

## 2. 注册流程（10 步）

### 步骤 1：退出公众号账号

1. 访问 `mp.weixin.qq.com`
2. 右上角点头像 → **退出登录**

### 步骤 2：进入注册入口

1. 在登录页面找到 **"立即注册"** 或 **"注册账号"** 按钮
2. 点击进入

### 步骤 3：选择账号类型

| 选项 | 选哪个 |
|---|---|
| 订阅号 | ❌ |
| 服务号 | ❌ |
| 小程序 | ❌ |
| **小游戏** | ✅ **选这个** |

### 步骤 4：填写基础账号信息

| 字段 | 填什么 |
|---|---|
| 邮箱 | 步骤 1.2 新建的邮箱 |
| 密码 | 8 位以上含字母数字 |
| 确认密码 | 同上 |
| 验证码 | 邮箱收到 |

提交后去邮箱点激活链接。

### 步骤 5：选择主体类型

- ✅ **个人**（你选这个）
- ❌ 企业、媒体、政府、其他组织

### 步骤 6：个人主体身份认证

| 字段 | 填什么 |
|---|---|
| 姓名 | 真实姓名（与软著、版权承诺书完全一致） |
| 身份证号 | 18 位 |
| 身份证正面 | 上传照片 |
| 身份证反面 | 上传照片 |
| 管理员手机号 | 你的手机号 |
| 管理员邮箱 | 你的常用邮箱（可以与注册邮箱不同） |

### 步骤 7：管理员微信扫码

1. 用你本人的微信扫码
2. 走完人脸识别和确认
3. 完成管理员绑定

### 步骤 8：提交审核

1. 确认所有信息
2. 点 **"提交审核"**
3. 等待 1-7 个工作日（节假日顺延）

### 步骤 9：审核通过后，创建小游戏

1. 收到审核通过邮件后，重新登录 `mp.weixin.qq.com`
2. 此时进入的是**小游戏后台**（不是公众号）
3. 找到 **"创建小游戏"** 或 **"新增小游戏"** 入口
4. 填写：
   - **小游戏名称**：`秦灭六国`
   - **小程序类目**：`角色扮演` 或 `策略`（看后台实际可选哪个）
   - **小游戏标签**：`策略`、`角色扮演`、`历史`、`剧情`
   - **简介**：（从 [01-平台基础信息与提审文案.md](./01-平台基础信息与提审文案.md) 复制）
   - **图标**：上传 1024×1024 PNG（用 [小游戏头像候选.svg](./小游戏头像候选.svg) 导出的）
5. 提交

### 步骤 10：拿到 AppID

1. 创建小游戏成功 → 进入 **设置 → 开发管理 → 开发设置**
2. 找到 **AppID（小程序 ID）** — 这一栏就是
3. 格式：`wx` 开头 + 16 位十六进制（**共 18 位字符**）
4. 截图发给我，我帮你填进项目配置

## 3. 必做的安全事项

### 3.1 AppSecret 不要外传

- 找到 AppID 后，**顺手生成 AppSecret**
- AppSecret 是你小游戏与微信服务器通信的密钥
- ⚠️ **绝对不要**写入代码、文档、公开仓库、聊天记录
- 只能保存在你本地安全的地方（密码管理器、本地加密文件）

### 3.2 IP 白名单

- 在"开发管理 → 开发设置"里，配置 **IP 白名单**（如果后续需要服务器调用）
- 当前版本不需要服务器，**可以不配**

### 3.3 服务器域名

- 同样在"开发管理 → 开发设置" → **服务器域名**
- **当前版本不需要配置**（项目本地存档，不调用任何外部网络）

## 5. 常见卡点速查

| 卡点 | 原因 | 解决 |
|---|---|---|
| 邮箱被提示"已被注册" | 注册过任何微信公众平台账号 | 新建一个邮箱 |
| 找不到"小游戏"账号类型 | 罕见；可能浏览器缓存 | 硬刷新（Ctrl+Shift+R）或换浏览器 |
| 微信扫码失败 | 微信本身未实名 | 先把微信实名 |
| 人脸识别失败 | 用了别人微信扫码 | 必须用本人的微信 |
| 审核状态长时间没更新 | 平台正常处理中 | 1-7 个工作日，急也没用 |
| 创建小游戏失败 | 名字"秦灭六国"被占用 | 先在 mp.weixin.qq.com 搜一下，没被占用才注册 |
| 创建小游戏失败 | 类目选择不符 | 个人主体一般可选"角色扮演"/"策略"，选实际玩法匹配的 |
| 找不到 AppID | 还没创建小游戏 | 创建小游戏后才能看到 AppID |

## 6. 个人主体游戏类目实战经验

微信小游戏**个人主体**目前能选的类目比较有限：

| 实际玩法 | 建议类目 | 是否需要版号 |
|---|---|---|
| 角色扮演 | 角色扮演 | **首版无付费无广告一般不需要** |
| 策略 | 策略 | 同上 |
| 棋牌 / 棋类 | 棋牌 | **需要版号**（不要选） |
| 捕鱼 | 捕鱼 | **需要版号**（不要选） |
| 模拟经营 | 模拟经营 | 可能需要版号 |

**关键原则**：
- 选**实际玩法最匹配**的类目，不要为了过审而选错类目
- 首版（无内购、无广告、无虚拟支付）一般不需要版号
- 上线后**不要主动**接入商业化能力（广告 / 支付），否则会触发额外的版号/资质要求
