《秦灭六国》提审前自检与签字模板

本文档用于：你在完成小游戏 Canvas/引擎迁移、准备提审包的最后阶段，把所有审核要点逐项核对并形成最终可提交版本。

一、提审前必检项（个人开发者）

1. 主体一致性
[ ] 软著证书著作权人 = 微信主体 = 抖音主体 = 本人真实姓名
[ ] 软著软件全称 = 小游戏名称
[ ] 软著软件版本号 = 平台提交的版本号
[ ] 联系人姓名/电话/邮箱与平台账号一致

2. 资源与代码
[ ] 提审包已移除外链（微信、Telegram、B站、机核、反馈入口）
[ ] 提审包已移除或打码微信/Telegram 二维码
[ ] 提审包已确认媒体资源来自平台允许的域名或包内资源
[ ] 提审包不再使用 document、window、localStorage、new Audio
[ ] 提审包已加入平台必接能力（抖音侧边栏复访）
[ ] 提审包没有开发者控制台/调试入口

3. 内容与文案
[ ] 健康游戏忠告完整呈现
[ ] 适龄提示与后台提交一致

[ ] 用户服务协议已填写联系信息

[ ] 未使用未授权的品牌、商标、公众人物形象

4. 体验与可玩性

[ ] 存档、读档、重置、战前回卷均可正常使用
[ ] 战斗、追截、救援、撤离界面无功能卡死
[ ] 横屏/竖屏与不同分辨率下排版合理

5. 平台账号

[ ] 抖音开放平台账号已注册并完成个人主体认证

六、官方提交路径

微信小游戏：登录微信公众平台 → 小游戏 → 设置 → 资质管理 / 备案 / 版本管理
抖音小游戏：登录抖音开放平台 → 我的应用 → 小游戏 → 基础设置 / 资质信息 / 版本管理
软著：中国版权保护中心综合服务平台 → 软件登记 → 软件著作权登记

七、提交后等待与处理

[ ] 微信小游戏预计审核：13–37 个工作日（IAA/无虚拟支付）
[ ] 抖音小游戏版本审核：1–7 个工作日（实际以后台为准）
[ ] 软著证书领取：受理后 30–60 日内
[ ] 任何平台驳回 → 在 7 个工作日内按驳回理由修改并重新提审
[ ] 软著驳回 → 按补正通知修改并重新提交

八、个人开发者常见驳回原因

微信小游戏：
- 主体姓名与软著著作权人不一致
- 提交材料中含其他游戏的截图、图标或文字
- 健康游戏忠告缺失或被裁切
- 软著登记名称与小游戏名称不一致
- 类目选择与实际玩法不符
- URL 参数预览页被提交到正式版

抖音小游戏：
- 自审报告未在后台确认
- 备案截图不完整或与提审版本不一致
- 游戏介绍字数、敏感词、诱导分享等违反运营规范
- 未接入侧边栏复访能力
- 游戏名称含敏感词或与软著不一致

软著：
- 软件全称与小程序/小游戏名称不一致
- 源代码页数不足 60 页或每页行数不足
- 文档鉴别材料未按规则整理
- 著作权人信息与平台主体不一致
