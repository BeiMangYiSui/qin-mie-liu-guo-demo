《秦灭六国》个人开发者发布准备总表

本目录文件由 AI 助手按你“个人开发者、只有个人微信和抖音账号、没有软著、还没有平台账号”的现状，整理出的可直接使用或参考的发布准备材料。所有材料与当前项目代码、官方公开规则保持一致；如平台规则、官方模板有更新，以平台后台当时实际要求为准。

1. 已准备的文件

1.1 平台提交文案与表单
- 小游戏发布材料草案.txt
  包含游戏名称/简介/详细介绍/关键词/版本说明、自审自查报告草案、隐私政策草案、用户服务协议草案、平台截图清单、软著申请信息、平台截图素材清单、技术改造清单和官方核对入口。
- 小游戏平台提交资料.json
  结构化的微信/抖音提交数据：游戏信息、开发者占位、隐私声明、平台材料清单、强制接入能力、截图计划、素材授权核验、当前项目状态。已通过 node 验证 JSON 有效。
- 个人开发者注册与软著申请顺序.txt
  5 步执行顺序：锁定名称 → 注册账号 → 准备软著 → 迁移项目 → 提交平台资质；含中国版权保护中心官方链接、平台官方链接、当前不要做的事。
- 软著申请表示例.txt
  按中国版权保护中心在线申请表字段准备的初稿，含软件基本信息、著作权人信息、功能说明、源代码/文档鉴别材料路径、官方流程、提交前自检。
- 素材授权与适龄提示稿.txt
  全部素材授权核验表、提审版必删/必改/必带、12+ 适龄说明、健康游戏忠告、防沉迷措施、本人原创声明。

5. 当前不要做的事

- 不要先用一个名字申请软著，再换一个名字创建小游戏
- 不要用个人微信号或抖音号直接当作平台账号
- 不要在没有审核版前先做支付/内购/虚拟货币
- 不要把当前 Vite dist 目录直接作为小游戏包上传
- 不要在软著/平台提交时使用未确认授权的 AI 图、AI 音乐、第三方字体
- 不要为了通过而选择不符合实际玩法的游戏类目

7. 下一步建议

1. 在微信公众平台和抖音开放平台分别注册账号，填好小游戏名称
2. 在中国版权保护中心官网以“秦灭六国 / V1.0 / 本人真实姓名”申请软著
3. 等待软著的同时，挑选微信或抖音进行小程序/小游戏 Canvas 迁移
4. 完成迁移后，重新生成软著材料、重新截图、按平台流程提审

以上材料与项目状态保持一致；如平台规则或项目代码后续有更新，重新执行 `npm run soft-copyright` 即可一键刷新软著材料。
