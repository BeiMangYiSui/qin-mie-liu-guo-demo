《秦灭六国》小游戏发布材料草案

用途：微信小游戏 / 抖音小游戏个人开发者发布准备
说明：本文档是根据当前项目代码、现有素材和两家平台公开规则整理的可直接填报草案。带“【待填写】”的内容必须由开发者本人补充；平台后台当前表单、审核提示和官方模板优先于本文档。

一、当前项目审计结论

1. 产品定位
- 游戏名称：秦灭六国
- 当前形态：React 19 + Vite 7 的浏览器 Web Demo
- 类型建议：叙事 RPG / 轻策略 / 回合制战斗
- 内容：战国末年架空叙事，包含剧情阅读、分支选择、三人小队战斗、救援、追截、结算和本地存档
- 当前商业模式：无登录、无内购、无广告、无用户投稿；建议首版按 IAA/非虚拟支付方向准备，但当前代码还没有接平台广告
- 当前素材规模：public 目录约 73MB，主要是图片、配音、BGM 和音效

2. 不能直接上传为小游戏的原因
- 微信小游戏和抖音小游戏运行环境均不是浏览器，默认没有 BOM/DOM，也没有 document、window、HTML 元素和 HTMLAudioElement。
- 当前入口使用 ReactDOM、BrowserRouter、document.getElementById；战斗界面依赖大量 HTML/CSS DOM，音频依赖 new Audio，图片依赖 new Image，存档依赖 localStorage。
- 当前媒体资源通过 https://stats.puck-muling.top/game/ 外部 CDN 加载，必须改为平台允许的域名并配置白名单，或打入小游戏资源包。
- 当前标题页含微信、Telegram、B站、机核和反馈入口；小游戏审核版应先移除外链、二维码和导流按钮。
- 结论：现有 Web 版可以继续作为网页 Demo，但不能直接当作微信/抖音小游戏代码包上传。最稳妥的迁移路线是保留 src/game/story.ts、battle.ts、scenarios.ts、defenseBattle.ts、tutorial.ts 等纯逻辑，重做 Canvas/UI 渲染层；或改用已适配小游戏的 Cocos/Laya/Egret 等引擎重建表现层。

三、可直接填入平台的产品文案

1. 游戏名称
秦灭六国

2. 一句话简介
战国末年叙事策略小游戏，在历史结局已定的时代，带领三人小队完成调查、护送与撤离，选择方法并承担代价。

3. 详细介绍（控制在平台要求的字数范围内）
《秦灭六国》是一款战国末年背景的叙事策略小游戏。玩家扮演秦军秘密行动头领北芒，与医者小满、剑士青翎组成三人小队，在郑地、新郑等虚构化历史场景中推进调查、护送、救援和撤离任务。游戏以章节剧情、人物对话、分支选择和轻量回合制战斗为主要玩法，战斗中需要根据敌方意图安排行动，目标不只包括击败敌人，也包括保护人员、夺取物证、守住退路和控制伤亡。游戏不设置等级、装备和付费抽取，玩家的选择会影响后续叙事、战斗配置和章末结算。作品对部分历史事件时间线作戏剧性合并，内容仅用于架空叙事体验。

4. 搜索关键词候选
秦灭六国、战国、历史剧情、叙事RPG、策略战斗、回合制、分支选择、单机剧情

5. 版本更新说明候选
首个可玩版本，包含序章与第一章主要剧情、分支选择、轻量回合制战斗、救援/追截玩法、章末结算和本地进度保存。版本不包含登录、内购、广告和用户自定义输入功能。

6. 运营模式
首版：无内购、无广告、无虚拟货币、无抽奖、无用户充值。
后续如接广告：仅在平台审核通过并接入官方广告 SDK 后按 IAA 模式运营，广告加载失败时直接提供正常游戏流程，不阻断关卡。

7. 内容分类填写建议
- 首选：角色扮演或策略类中最接近的官方类目
- 内容形态：剧情阅读 + 轻量回合制战斗
- 不要选择：棋牌、捕鱼、博彩、模拟经营等与实际玩法不符的类目
- 历史场景：填写为架空化演绎场景，不使用国家标准地图，不还原现实军事设施
