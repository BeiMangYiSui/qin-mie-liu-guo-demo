## 一、本次重构做了什么

### 1.1 业务代码无侵入适配（核心成果）

| 文件 | 改动 | 效果 |
|---|---|---|
| `src/game/audio.ts` | 重构 BGM/voice/sfx 三轨管理，分流 `IS_MINI_GAME`。浏览器版保留 `HTMLAudioElement` + requestAnimationFrame 淡入淡出；小游戏版走 `platform/createAudio`，淡入淡出用 setTimeout 步进 | 浏览器版 + 小游戏版共用同一份业务代码 |
| `src/hooks/useLoadedImage.ts` | 图片加载分流。浏览器版保留同步缓存命中（`new Image().complete`）；小游戏版走 `platform/loadImage` Promise | 切场景不黑屏（小游戏版首次会有 1 帧延迟） |
| `src/game/save.ts` | 已通过 `@/platform` 别名间接调用，浏览器版保留 localStorage，小游戏版走 `wx.setStorageSync` | **0 改动** |
| `src/main.minigame.tsx` | 已存在；包含健康游戏忠告、适龄提示、首次交互解锁音频、抖音侧边栏复访 | **0 改动** |

### 1.2 构建产物目录结构（webview 渲染模式）

```
dist-minigame/                                # 微信小游戏
├── game.js                                   ← 根级 V8 入口（post-clean 生成）
├── game.json                                 ← 小游戏配置（pages: ["pages/index/index"]）
├── project.config.json                       ← IDE 配置（appid 由环境变量注入）
├── sitemap.json                              ← 微信搜索 sitemap（disallow all）
├── pages/
│   └── index/
│       ├── index.html                        ← webview 入口（post-clean 生成）
│       ├── index.js                          ← Vite 打包主 JS（391 KB / gzip 127 KB）
│       └── main-Dx4J7ywJ.css                 ← Vite 打包 CSS（133 KB / gzip 24 KB）
├── assets/                                   ← Vite 处理后的图片资源（11 MB）
├── bgm/                                      ← BGM 拷贝（13 MB）
├── sfx/                                      ← 音效拷贝（2.6 MB）
└── voice/                                    ← 配音拷贝（16 MB）

dist-minigame-douyin/                         # 抖音小游戏
├── app.js                                    ← 根级 V8 入口（带 App() 生命周期）
├── app.json                                  ← 全局 pages + window 配置（renderer: webview）
├── project.config.json                       ← IDE 配置（默认从根目录 project.config.json 继承 appid）
├── pages/index/{index.html, index.js, main-*.css}
├── assets/ bgm/ sfx/ voice/
```

**主包代码（小程序运行时加载）**：约 525 KB（JS + CSS，未 gzip）
**总包（包含资源）**：约 36.39 MB（远超首包 4MB 上限）

   - 项目目录：`/Users/zhuangxiji/Desktop/CC/qin-mie-liu-guo-demo/dist-minigame`

| 报错 | 原因 | 解决 |
|---|---|---|
| `game.json 解析错误` | `game.json` 字段错误 | 检查 `dist-minigame/game.json` 的 `pages` 字段是否为 `["pages/index/index"]` |

| `wx is not defined` | 在 IDE 的模拟器里 wx 全局不存在 | 用「真机调试」而非「模拟器」调试 |
| `请求域名不在合法列表` | 业务用了 CDN | 见 §六 资源迁移 |

## 六、资源迁移方案（必须做的 4MB 首包处理）

### 6.1 当前问题

| 资源 | 大小 | 必须放主包吗 |
|---|---|---|
| `pages/index/index.js` | 391 KB | ✅ 必须（首屏加载） |
| `pages/index/main-*.css` | 133 KB | ✅ 必须 |
| `assets/*.webp/png`（背景） | ~5 MB | ❌ 可放主包少量 + 其余迁 CDN |
| `bgm/*.mp3` | 13 MB | ❌ 全部迁 CDN |
| `sfx/*.mp3` | 2.6 MB | ⚠️ 短音效放主包，长音效迁 CDN |
| `voice/*.mp3` | 16 MB | ❌ 全部迁 CDN |

### 6.2 推荐 CDN 方案

1. **域名**：已备案、HTTPS、境内的对象存储（腾讯云 COS / 阿里云 OSS）
2. **目录结构**：
   ```
   https://your-cdn.example.com/qin-mie-liu-guo/
   ├── assets/{全部图片}
   ├── bgm/{全部 BGM}
   ├── sfx/{全部音效}
   └── voice/{全部配音}
   ```
3. **代码侧改动**：`src/lib/cdn.ts` 把 `MEDIA_CDN` 从空字符串改为你的 CDN 域名
   ```typescript
   // 当前（小游戏版返回包内路径）：
   export const MEDIA_CDN = IS_MINI_GAME ? '' : 'https://stats.puck-muling.top/game/'
   // 改为（小游戏版走 CDN）：
   export const MEDIA_CDN = IS_MINI_GAME ? 'https://your-cdn.example.com/qin-mie-liu-guo/' : 'https://stats.puck-muling.top/game/'
   ```
4. **业务侧改动**：在 `src/main.minigame.tsx` 里加一个「远程资源预取」步骤，进游戏后异步预取 BGM/voice 到 IndexedStorage（或小程序缓存）

### 6.3 域名白名单（两个平台都要配置）

| 平台 | 后台位置 | 配置 |
|---|---|---|
| 微信 | mp.weixin.qq.com → 开发管理 → 服务器域名 → request / downloadFile 合法域名 | `https://your-cdn.example.com` |
| 抖音 | 抖音开放平台 → 小游戏 → 设置 → 服务器域名 | 同上 |

### 6.4 详细分包方案

参考 [`docs/release/微信小游戏资源分包方案.md`](file:///Users/zhuangxiji/Desktop/CC/qin-mie-liu-guo-demo/docs/release/微信小游戏资源分包方案.md)（已写好 22 个分包的详细切分方案）

## 九、常见问题

### Q1: IDE 打开 dist 报错「找不到 game.json / app.json」

A: `npm run clean:minigame:wx` 清掉旧产物，重新 `npm run build:minigame:wx`。

### Q2: 模拟器正常，真机黑屏

A: 检查 `game.json` / `app.json` 的 `renderer: "webview"` 是否设置；微信小游戏模拟器对 webview 渲染支持有限，**必须真机调试**。

### Q3: 「请求不在合法域名列表」

A: 见 §六 资源迁移 — 需要把外部域名加到 mp.weixin.qq.com 后台。当前包内资源是相对路径，不会有这个问题；用 CDN 后才会触发。

### Q4: 启动页一闪而过，游戏逻辑不加载

A: 检查 `pages/index/index.html` 里 `<script src="./index.js">` 路径；Vite 重新构建后文件名带 hash，post-clean 会自动探测并写入 HTML。

### Q5: 提审被拒「含可外链的社交账号信息」

A: 检查 post-clean 是否成功删除了 `wechat-qr.png` / `telegram-qr.png`。看日志 `[clean] removed assets/wechat-qr.png` 是否出现。

### Q6: 提审被拒「未声明敏感权限」

A: 微信小程序如果用了 `wx.getLocation` 等 API 必须在 `game.json` 的 `requiredPrivateInfos` 字段声明。当前未声明，是 OK 的。
