# 微信小游戏发布 - 当前阶段速查卡

> 状态：等你在小程序账号注册流程中
> 目标：拿到 wx 开头的 18 位 AppID

---

## 现在该做什么（一屏看完）

### 在哪个页面

`mp.weixin.qq.com` → 退出公众号 → 登录页 → **"立即注册"** → **选"小程序"**

### 不会再卡住的 4 步

| 步骤 | 填什么 | 关键提示 |
|---|---|---|
| 邮箱 | **新建的邮箱**（163/Gmail/Outlook） | 这个邮箱没注册过任何微信公众平台账号 |
| 主体 | 选 **个人** | 不要选企业 |
| 身份证 | 正面 + 反面 + 18 位身份证号 | 真实姓名（与软著著作权人一致） |
| 微信扫码 | 你的个人微信扫码 | 必须本人微信 + 已实名 |

### 提交后等多久

1-7 个工作日。审核通过你会收到邮件 + 短信。

### 拿到 AppID 后

进入小程序后台 → 设置 → 基本信息 → 找到 **AppID（小程序 ID）**（wx 开头 18 位）

**截图发给我**，我跑一行命令搞定所有配置。

**运行命令**：

```bash

npm run build:minigame:wx           # 平时构建提审包
npm run compress:assets             # 压缩素材
```

## 卡住了怎么办

| 看到什么 | 怎么办 |
|---|---|
| 邮箱"已被注册" | 换新邮箱 |
| 没有"小游戏"选项 | 选"小程序"（小游戏归在小程序） |
| 看不到"个人"主体 | 罕见，截图给我 |
| 微信扫码失败 | 先把微信本身实名 |
| 创建"秦灭六国"失败 | 名字可能占用，截图给我 |
| 看不到 AppID | 必须先"创建"小程序 |
