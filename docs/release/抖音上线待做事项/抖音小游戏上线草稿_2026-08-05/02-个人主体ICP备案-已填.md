## 四、可能需要的补充材料（按属地要求）

- **身份证地址与通讯地址跨省**：按属地要求提供居住证、本人为户主的房产证或近三个月社保证明。
- **上海/江苏**通常要求当地居住证。
- **通讯地址在广东**：按后台要求提交《个人互联网信息服务核准承诺书》（以提交当日平台模板为准）。
- 名称、简介或经营内容命中出版、文化等前置审批关键词但实际不经营：按平台模板提交《不涉及前置审批承诺书》。
- 其他补充材料：情况说明、授权书、真实性核验单等。

## 五、备案时序与提醒

1. 在抖音控制台：**基础设置 → 备案信息 → 去备案**。
2. 填写并提交主体、负责人、小游戏及附件信息，完成本人核验（抖音扫码）。
3. 平台初审通常为 **1—6 个工作日**，以实际为准。
4. 收到工信部短信后，**必须在 24 小时内**登录工信部备案管理系统完成核验。
5. 短信核验后进入**属地管局审核**，一般 **1—20 个工作日**（平台说明）。
6. 备案成功后平台自动展示备案号，**无纸质证书**。
