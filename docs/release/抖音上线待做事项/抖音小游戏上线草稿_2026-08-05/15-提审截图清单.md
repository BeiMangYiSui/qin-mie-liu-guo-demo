# 15 — 提审截图清单（8 张）

> 来源：基于 `小游戏发布材料草案.txt` §七 + 材料包 `12_提审截图_三张/重要_迁移后必须重拍.txt`。
> 用途：抖音 / 微信小游戏后台"提审截图"上传清单。

---

## ⚠️ 重要提醒

材料包现有的 3 张 png 截图来自**当前 React/Vite 网页版基线**，仅用于**选图和材料预审**。

> 完成抖音小游戏适配后，**必须在最终真机提审版本重新截图**，确保画面与提交版本一致。

---

## 一、推荐 8 张截图清单

抖音小游戏"提审截图"通常要求 **3–5 张** 主视图（不同平台要求不同，建议**一次准备 8 张**）。建议顺序：

| 编号 | 标题 | 关键元素 | 顺序 | 来源 / 操作 |
|------|------|----------|------|-------------|
| 01 | **首页 / 健康提示** | 游戏名称、主视觉、开始按钮、**健康游戏忠告 + 适龄提示** | 必选 | 抖音开发者工具 → 首屏 → 截图（含健康忠告段落） |
| 02 | **剧情对话** | 人物立绘、背景、对白、继续操作 | 必选 | 进入「案发 S1」后截图 |
| 03 | **分支选择** | 完整显示选择项和反馈结果 | 必选 | 进入「C7 三择其一」截图 |
| 04 | **回合制战斗** | 双方单位、任务目标、行动按钮、战斗反馈 | 必选 | 进入「教学战 S6」或「护送战 C4」截图 |
| 05 | **特殊玩法（救援/追截）** | 展示特殊玩法、计时与操作反馈 | 推荐 | 进入「C7 火场」或「撤离战」截图 |
| 06 | **章末结算** | 展示玩家选择造成的差异和结算信息 | 推荐 | 完成第一章后进入「C8 章末」截图 |
| 07 | **存档 / 设置** | 本地存档功能与重置入口 | 可选 | 进入菜单 → 存档界面截图 |
| 08 | **适龄 / 健康忠告特写** | 与平台提交内容一致 | 可选 | 长按设置后弹窗特写截图 |

---

## 二、截图前必查清单（避免提审退回）

每张截图上传前核对：

- [ ] **不含** 微信、Telegram、B站、机核 二维码 / 外链 / 联系方式
- [ ] **不含** 测试 / Demo / Debug / 调试字样
- [ ] **不含** 第三方品牌标识（除非已授权）
- [ ] **不含** 玩家昵称 / 评论 / 直播画面
- [ ] URL 栏 / 调试面板 / 控制台输出清空
- [ ] 截图来自**最终真机提审版本**，与游戏实际表现完全一致
- [ ] 同一截图不混用 PC、网页旧版或开发版
- [ ] 头像 / 主视觉与 `13_图标/秦灭六国_图标_512.png` 设计风格一致

---

## 三、自动截图脚本（已就绪，待业务迁移完成）

仓库已具备：**`scripts/take-platform-screenshots.mjs`**

- 自动启动 Playwright Chromium
- 访问 `localhost:5173`（开发服务器）
- 通过 `?stage=` 参数跳转到各阶段
- 输出 `docs/screenshots/01-home.png ... 08-health.png`

> ⚠️ 当前是 React/Vite 网页版基线，迁移完成后请**更新此脚本**：
> - 把 `BASE_URL` 改为抖音开发者工具预览地址
> - 增加抖音小游戏首屏（健康忠告页）的截图阶段
> - 增加存档页 / 设置页 / 结算页的截图

---

## 四、人工截图建议

若自动脚本不适配，可用手机在抖音开发者工具**真机调试模式**截屏：

1. **横屏**：保持 1280×800 或 16:9
2. **清晰度**：保存为 png；分辨率 ≥ 720p
3. **存储**：`docs/screenshots/douyin-final/01-08.png`
4. **文件大小**：单张 ≤ 1MB（超过会被压缩）
5. **命名**：与上表顺序一致，方便平台一一对应
