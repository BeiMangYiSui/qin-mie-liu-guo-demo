# 14 — 第三方依赖许可摘要（THIRD_PARTY_NOTICES 占位）

> 用途：软件著作权申报 + 平台自查 — 按各依赖许可证要求保留版权声明和许可证文本。

---

## ⚠️ 当前状态

`package-lock.json` 显示项目依赖包含 **MIT、Apache-2.0、BSD、ISC、CC-BY-4.0** 等许可。**正式生成 `THIRD_PARTY_NOTICES.md` 必须在 Build 完成后用脚本解析每个生产依赖的 LICENSE 文件**。

---

## 一、必须包含的依赖项（已知大类）

下面是基于 `package.json` 推断的关键大类；**最终生成应只列生产依赖（`dependencies`，不含 `devDependencies`）**：

| 大类 | 代表依赖 | 许可证 |
|------|----------|--------|
| React | react、react-dom | MIT |
| Routing | react-router / react-router-dom | MIT |
| State / Query | @hookform/resolvers、react-hook-form、zod | MIT |
| UI | @radix-ui/*（21 个）、lucide-react、tailwindcss、tailwindcss-animate、tw-animate-css、class-variance-authority、clsx、tailwind-merge | MIT |
| Animation | embla-carousel-react、sonner、vaul、cmdk、recharts、react-day-picker、date-fns | MIT |
| Form / Input | input-otp | MIT |
| Theme | next-themes | MIT |
| Layout | react-resizable-panels | MIT |

> `devDependencies`（vite / @vitejs/plugin-react / typescript / playwright / eslint 等）开发期使用，**不必进入 NOTICE**，但分发渠道若捆绑，应按其许可附文。

## 二、`THIRD_PARTY_NOTICES.md` 推荐生成方式

```bash
# 1. 收集所有 production 包
npm ls --omit=dev --json > tree.json

# 2. 遍历每个包取其 LICENSE 文件
node -e '
const tree = require("./tree.json");
const walk = (node, path=[]) => {
  const p = [...path, node.name].filter(Boolean).join("/");
  if (!node.dependencies) return;
  for (const [name, dep] of Object.entries(node.dependencies)) {
    console.log(p + "/" + name);
    if (dep.dependencies) walk(dep, [...path, name]);
  }
};
walk(tree.dependencies || {});
'
```

或使用社区工具：

- `npx generate-license-file --input package.json --output THIRD_PARTY_NOTICES.md`
- `npx license-report --output=html/md`
