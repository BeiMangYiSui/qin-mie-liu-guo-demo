# 13 — 健康游戏忠告（平台标准文案）

> 来源：基于 `小游戏发布材料草案.txt` §四第 3 项。
> 用途：游戏内常驻提示、加载页、设置页底部。

## 📌 标准文案（推荐）

```
抵制不良游戏，拒绝盗版游戏。
注意自我保护，谨防受骗上当。
适度游戏益脑，沉迷游戏伤身。
合理安排时间，享受健康生活。
```

> 这是中国大陆游戏行业主管部门长期沿用的标准文本，建议在抖音小游戏"游戏内"和"游戏外宣传"都使用该标准版。修改字句可能被视为不符合规范。
