- [ ] 个人身份证明及申请表

- [ ] 涉及他人代码、素材或作品时的**许可证和授权**：不把第三方依赖源码作为本人原创申报

## 四、源代码范围建议

以最终抖音小游戏工程的**原创业务代码**为准，优先选取：
- 剧情流程（src/game/scenarios.ts、src/game/story.ts）
- 战斗逻辑（src/game/battle.ts、src/game/defenseBattle.ts、src/game/tutorial.ts）
- 存档系统（src/game/save.ts、src/game/battleRetry.ts）
- 场景与资源管理（src/sections/* 与 src/ui/* 的可公开子集）

**严禁放入鉴别材料**：
- node_modules
- 第三方 UI 组件库（如 lucide-react、@radix-ui/*）
- 构建产物、.map 文件
- 密钥、服务器账号、个人信息、未获授权素材
- docs/小说素材（受版权保护资料）

## 五、软著与平台一致性核对

| 核对项 | 通过标准 |
|--------|----------|
| **名称** | 小游戏名与软著全称（可忽略"游戏软件"等后缀）或简称一致 |
| **著作权人** | 软著著作权人 = 抖音个人主体姓名 = **师朋飞** |
| **版本** | 证书版本、申请材料和首次提审版本逻辑一致 |
| **真实性** | 登记号可在官方渠道查询，证书图片清晰无瑕疵 |
| **唯一性** | 同一软著不用于平台上的其他在线小游戏 |
| **改名影响** | 软著或名称变更可能触发重新小游戏备案和 ICP 备案 |

## 七、申请流程建议

1. **准备鉴别材料**：从 dist-minigame-douyin/ 取发布版本代码 → 脱敏（替换密钥/邮箱/身份证）→ 打印或 PDF，连续页眉页码。
2. **准备用户手册**：与 `01-基础信息` + `04-用户服务协议` + `08-技术迁移报告` 提炼合并（≥ 60 页）。
3. **撰写申请表**：本文件第一节已有完整字段。
4. **登录中国版权保护中心在线登记系统**：
   - https://www.ccopyright.com.cn/
   - 或通过代理记账/版权服务公司加急办理（建议首次：30 工作日；加急：10–15 工作日；费用按 2024 年标准 ¥900 普通 / ¥2,000 加急；**实际费用以官方最新公告为准**）
5. **上传材料 → 等待受理 → 等待审查 → 等待制证 → 收到证书 → 回填软著号到 10 节**
6. **同步回填**到抖音小游戏基本信息、平台 ICP 备案。
