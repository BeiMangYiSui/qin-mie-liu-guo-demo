## 二、AI 美术证据登记字段

每张 AI 生成图片应保留：

| 字段 | 填写要求 |
|------|----------|
| 资产编号 | 唯一编号，例如 `IMG-BG-001` |
| 最终文件 | 相对路径、文件名、SHA-256 |
| 生成工具 / 模型 | 产品名称、模型版本、账号主体 |
| 生成时间 | 精确到分钟、注明时区（东八区） |
| 提示词 | 完整正负提示词、参考图及其权利 |
| 编辑记录 | 裁切、合成、修图、重绘和人工贡献 |
| 商用依据 | 套餐、订单、许可条款链接和条款截图 |
| 审核结论 | 无水印、无可识别第三方 IP、无乱字、无肖像风险 |

> 模板表见 `14-三方依赖许可摘要.md` 末附表。

## 三、配音与音频证据登记字段

### 配音

- 文本
- 角色
- 音色 ID
- 语速 / 音调
- 生成命令
- 生成时间
- 服务账号
- 商业许可（含条款截图）

### BGM / 音效

- 完整提示词
- 时长 / 文件规格
- 生成工具
- 订单或调用记录
- 后期处理

> 若音色**模仿或接近真人**，必须确认服务条款允许且**不存在未经授权的声音克隆**。
>
> 保存原始文件和最终压缩文件的 SHA-256；替换时保留版本关系（v1/v2/...）。

## 四、开源软件合规

`package-lock.json` 显示项目依赖包含 **MIT、Apache-2.0、BSD、ISC、CC-BY-4.0** 等许可。

**发行前必须**：
1. 从最终生产依赖生成 `THIRD_PARTY_NOTICES.md`（详见 `14-三方依赖许可摘要.md`）
2. 按各许可证要求保留版权声明和许可证文本
3. 不要仅依赖 package-lock 中的 license 字段（需解析每个依赖的实际 LICENSE 文件）
