## 版权承诺书底稿

本人师朋飞系《秦灭六国》小游戏的开发者及拟运营者。本人承诺：

1. 游戏原创程序代码、剧情文案、角色设定、玩法规则和界面设计由本人合法创作或取得相应权利。
2. 对第三方开源软件，将依据相应许可证使用并保留版权与许可声明。
3. 对 AI 辅助生成或第三方取得的图片、配音、音乐、音效和字体，已核对商业使用条件并保存生成记录、订单、授权书或许可条款。

7. 如发生权利争议，本人将及时停止使用争议内容、配合平台处理并依法承担责任。

## AI 图片证据字段

每个最终图片至少保留：资产编号、相对路径、SHA-256、生成工具与模型、账号主体、生成时间、完整提示词、参考图及其权利、人工编辑记录、当时有效的商用条款截图、最终审核结论。

## 音频证据字段

每个配音/BGM/音效至少保留：文件名、用途、生成或取得方式、工具/音色/素材库、账号主体、生成或购买时间、订单/调用记录、商用范围、真人声音或音乐权利说明、原始文件与最终文件 SHA-256。

├── 03_AI图片生成记录/

证据目录可存放在非公开、受控的个人云盘或加密硬盘，不建议把身份证、订单隐私、平台密钥或完整授权凭证直接提交到公开 Git 仓库。

## 提审放行条件

- 所有实际使用的图片与音频均能追溯到合法来源。
- 没有“先上线、被投诉再补授权”的项目。
- `public/assets/review`、`public/assets/unused`、二维码和研发参考资料不进入正式包。
- 最终名称、图标、启动页、软著和主体权利链一致。
