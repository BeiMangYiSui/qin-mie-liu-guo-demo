# 06 — 《秦灭六国》游戏自审自查报告

游戏名称：秦灭六国  
软件版本：V1.0 / 小游戏版本 1.0.0  
开发及运营主体：师朋飞（个人）  
审核日期：____年__月__日

本报告为预填底稿。提交时如微信公众平台提供最新在线表单或模板，应将本报告内容迁移到平台模板并按要求手写签名、按手印或扫码确认。

## 一、产品与运营模式

- 单人剧情策略游戏，主要玩法为剧情阅读、线索查验、分支选择和轻量回合制战斗。
- 当前版本无账号注册、登录、好友、排行榜、聊天、论坛或用户内容发布。
- 当前版本无充值、内购、虚拟货币、抽奖、开箱、付费解锁和现金奖励。
- 当前版本无广告代码、第三方统计 SDK 和用户画像功能。
- 存档仅保存在用户设备本地，不上传开发者服务器。

## 二、内容自查

- 游戏为战国末期题材的原创虚构叙事，不含危害国家安全、破坏社会稳定或违反法律法规的内容。
- 不含色情、低俗、侮辱诽谤、邪教、封建迷信、赌博博彩或毒品相关内容。
- 不包含现实政治事件评论，不将现实党政机关、军警单位或公共人物作为可操控对象。
- 历史人物、机构、对白和事件经过存在艺术化处理，并通过历史题材说明明确不作为史实依据。
- 战斗、火灾、疾病和伤亡以文字、界面及非写实画面表现，不展示血腥肢解、虐杀、恐怖特写或鼓励现实模仿的危险行为。
- 游戏无用户自由输入，因此当前不涉及昵称、聊天、评论、图片上传和用户内容审核。
- 不使用国家标准地图，不展示现实敏感军事设施或可识别的国家秘密信息。

## 三、功能与商业化自查

- 无诱导分享、强制关注、二维码导流、外部社交账号和第三方平台跳转。
- 无虚假宣传、“国家级”“官方唯一”“第一”等无法证明的绝对化表述。
- 无支付、退款、广告收益、个人结算和虚拟财产处理。
- 如未来增加广告、支付、云存档、登录、社交或用户输入，将先完成所需资质、隐私评估和平台审核。

## 四、个人信息与数据安全自查

- `game.json` 的 `permission` 为空，`requiredPrivateInfos` 为空数组。
- 不调用头像昵称、手机号、位置、相机、相册、麦克风、通讯录、蓝牙或支付相关接口。
- 本地存档仅含关卡、剧情选择、战斗节点、设置和存档时间。
- 提审版不接入第三方统计、广告或跨境资源服务。
- 已起草隐私政策和后台个人信息处理清单；最终版本将以代码扫描结果复核。

## 五、未成年人保护自查

- 建议适龄等级为 12+，并准备了适龄说明和《健康游戏忠告》。
- 无付费、抽奖、连续签到奖励、陌生人社交和未成年人营销。
- 未成年人应在监护人指导下合理安排游戏时间。
- 如监管或平台要求接入实名认证、防沉迷或时长限制，将按最终运营模式和资质完成接入。

## 六、知识产权自查

- 原创程序代码、剧情和游戏规则以 Git 历史、源文件和软著材料留存。
- 第三方开源依赖按许可证使用，并将生成第三方许可清单。
- 美术、配音、BGM 和音效中存在 AI/工具生成内容，必须在提审前补齐生成记录、账号归属、提示词/工程文件、时间戳和商用条款快照。
- 未确认授权或无法追溯来源的素材不得进入提审包。
- 提审截图、图标和启动页均使用本游戏最终版本，不混入其他游戏或开发调试素材。

## 七、自审结论

在完成微信小游戏可运行版本迁移、软件著作权与平台资质办理、素材权利证据归档、备案、适龄设置、真机测试和最终代码扫描后，《秦灭六国》可提交微信平台内容与版本审核。上述前置项未完成前，本报告不作为已具备公开运营资格的证明。
