# 08 — 审核体验说明与截图计划

## 审核员体验说明

本游戏无账号登录、验证码、邀请码、付费或广告门槛，审核人员无需测试账号。

建议审核路径：

1. 启动游戏，查看《健康游戏忠告》和 12+ 适龄说明，点击屏幕继续。
2. 在标题页点击“奉令出发”。
3. 推进序章剧情，在证言或线索面板完成一次查验选择。
4. 继续至首次回合制战斗，根据敌方意图选择角色行动。
5. 进入第一章，体验护送、救援、追截或火灾选择等特殊玩法。
6. 完成章末结算，查看选择影响和史乘卡。
7. 打开菜单保存并读取进度；存档仅位于当前设备。

完整体验预计时长：【完成小游戏真机版后实测并回填】分钟。若完整流程超过审核常见可接受时长，应准备合规的审核直达能力或在审核备注中说明快速路径，且该能力不得面向正式用户形成隐藏调试入口。

## 必截画面

- 01 启动/标题页：游戏名、主视觉、开始按钮、健康提示清晰可见。
- 02 剧情页：人物立绘、背景、对白和继续操作。
- 03 线索/分支页：完整选择项和选择反馈。
- 04 战斗页：我方角色、敌方、行动按钮、目标说明。
- 05 特殊玩法：救援、追截或火灾决策中的一个代表画面。
- 06 章末结算：结果、评价、选择影响和继续入口。
- 07 存档/设置：保存、读取、删除或重置入口。
- 08 适龄与健康提示：与后台设置一致。

## 截图规则

- 仅从最终微信小游戏真机提审版本截取，不使用网页 Demo、UI 预览或设计稿冒充。
- 所有截图使用同一版本、同一名称和一致的美术资源。
- 不出现浏览器地址栏、开发者工具、调试文字、测试参数、帧率面板或报错。
- 不出现微信号、Telegram、B站、机核、二维码、外部链接或“关注后领取”等导流。
- 不出现未授权素材、其他游戏图标、平台水印或第三方品牌。
- 图片数量、尺寸、格式和单张大小以微信后台当日要求为准。
- 原始无损截图与上传压缩版本均归档，文件名包含版本号和日期。

- 字形、装饰和颜色不存在第三方商标或字体授权争议。

## 分享素材

若首版保留微信主动分享功能，应另备与游戏内容一致的分享标题和横向分享图，并确认分享由用户主动触发、不设置强制分享奖励。若分享能力不是上线必需，首版可关闭以减少审核变量。
