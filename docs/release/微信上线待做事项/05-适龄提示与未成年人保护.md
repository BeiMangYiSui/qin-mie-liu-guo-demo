# 05 — 适龄提示与未成年人保护说明

## 建议适龄标识

建议：12+。最终选择以微信公众平台适龄提示页面的现行标准和审核结果为准。

## 适龄说明（后台可复制）

本游戏是一款战国末年题材的单人剧情策略游戏，包含文字叙事、历史战争背景、非写实回合制战斗、火灾与人员伤亡等情节，但不展示血腥、肢解、恐怖特写或写实暴力。玩家需要阅读较多剧情文字、理解线索并作出策略选择，适合具备相应阅读理解能力的用户。游戏无充值、内购、抽奖、聊天、陌生人社交和用户内容发布功能。建议 12 周岁及以上用户使用，未成年人应在监护人指导下合理安排游戏时间。

## 健康游戏忠告

抵制不良游戏，拒绝盗版游戏。注意自我保护，谨防受骗上当。适度游戏益脑，沉迷游戏伤身。合理安排时间，享受健康生活。

## 游戏内展示建议

- 启动页展示游戏名称、12+ 建议标识和完整《健康游戏忠告》，并与微信后台设置一致。
- 优先使用平台适龄能力，不自行制作容易与官方认证混淆的图样。

## 未成年人保护自查

- [x] 无充值、付费、抽奖、开箱和虚拟货币。
- [x] 无签到奖励、连续登录奖励和强制分享奖励。
- [x] 无聊天、陌生人社交、排行榜和 UGC。
- [x] 无用户账号体系，不主动处理实名或年龄信息。
- [x] 不向未成年人定向推送广告或营销信息。
- [x] 战斗采用非写实表现，不含血腥肢解和恐怖特写。
- [ ] 上线前完成后台适龄设置，并用真机确认启动页文字清晰、不被安全区域遮挡。

## 内容控制边界

如后续增加更写实的暴力表现、付费、广告、社交、排行榜、用户输入或长线运营活动，必须重新评估适龄等级、未成年人保护、隐私和版号/防沉迷要求。
