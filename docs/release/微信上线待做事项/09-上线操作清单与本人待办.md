# 09 — 微信小游戏上线操作清单与本人待办

## 阶段 A：账号与名称

- [ ] 使用未注册其他公众平台账号的常用邮箱注册微信小游戏账号。
- [ ] 选择个人主体并完成本人微信扫码、实名认证和管理员绑定。
- [ ] 创建“游戏”类目小游戏，锁定名称“秦灭六国”。
- [ ] 记录 AppID、注册邮箱、管理员微信、主体姓名和平台通知渠道。
- [ ] 将 AppID 回填到本材料包和最终微信开发者工具配置；AppSecret 仅保存在安全位置，不写入前端或文档。

## 阶段 B：权利与审批

- [ ] 冻结 V1.0 软件名称、版本、主要功能和最终代码。
- [ ] 以师朋飞为著作权人申请“秦灭六国游戏软件 V1.0”软件著作权。
- [ ] 校验软著证书的名称、简称、版本、著作权人与微信主体一致。
- [ ] 在微信后台按实际运营模式查看游戏资质要求；下载并使用平台最新自审、授权或声明模板。
- [ ] 对版号/网络游戏出版审批要求取得平台或具备资质的专业机构书面确认；未取得明确合规结论前不开通商业化运营。

## 阶段 C：小游戏技术版本

- [ ] 完成 Canvas/小游戏引擎迁移，消除对浏览器 DOM、`document` 和普通 HTML 页面入口的依赖。
- [ ] 生成可由微信开发者工具直接导入并运行的小游戏工程，包含正确的项目配置、入口和资源方案。
- [ ] 将首包控制在微信当前限制内；大资源采用分包、远程资源或压缩策略。
- [ ] 远程资源只使用境内合规 HTTPS 域名，并在微信后台配置合法域名。
- [ ] 移除站外二维码、Telegram、B站、机核、调试入口、评审图和未使用素材。
- [ ] 确认 `permission` 为空、`requiredPrivateInfos` 为空，且代码扫描没有未声明隐私接口。
- [ ] 在至少一台 iOS 和一台 Android 真机测试启动、横屏、安全区、触控、音频、存档、切后台和恢复。

## 阶段 D：备案与隐私

- [ ] 在微信公众平台发起小程序/小游戏备案，按《02-小程序备案信息预填表》填写。
- [ ] 收到备案短信后在规定时限内完成工信部短信核验。
- [ ] 按属地管局或平台补正要求及时修改，保留备案申请和回执截图。
- [ ] 在微信后台填写《用户隐私保护指引》；以最终代码实际处理的信息为准。
- [ ] 在游戏内提供隐私政策和用户协议可访问入口。
- [ ] 完成 12+ 适龄提示设置，并与启动页文字保持一致。

## 阶段 E：素材与提审

- [ ] 补齐全部图片、配音、BGM、音效的来源和商用证据。
- [ ] 从最终真机版本拍摄提审截图并整理图标、简介、版本说明。
- [ ] 使用最终版本走完审核员体验路径，记录总时长和关键步骤。
- [ ] 打印/导出自审报告与版权承诺书，按微信最新要求手写签名、按手印或扫码确认。
- [ ] 上传体验版，邀请本人之外至少一名测试者完整通关关键路径。
- [ ] 提交版本审核；退回时逐条记录问题、版本号、修复内容和复核证据。

## 阶段 F：发布前最后检查

- [ ] 审核通过的代码与拟发布代码完全一致，不通过服务端开关恢复违规功能。
- [ ] 名称、图标、简介、截图、适龄、隐私、资质、备案信息一致。
- [ ] 无广告、支付、登录、外链、调试或未声明数据处理。
- [ ] 无空白页、黑屏、资源加载失败、按钮无响应、横竖屏错误或音频持续播放。
- [ ] 选择合适发布时间并保留回滚方案；发布后用非管理员普通微信账号复测。

## 只有本人能完成的事项

- 身份证、人脸、管理员微信和手机短信核验。
- 微信账号注册、主体实名、备案扫码/签署和后台提交。
- 软著申请确认、签字、证书接收和费用支付（如有）。
- 版权授权条款的真实性确认及订单/生成记录归档。
- 最终版号或平台合规路径的确认。
- 真机截图、审核沟通和正式发布按钮。

## 当前优先级

P0：微信账号/AppID、技术迁移、软著 V1.0 冻结。P1：素材权利证据、备案、隐私与适龄配置。P2：真机截图、体验版测试、自审签署和版本审核。P3：取得明确资质后再评估广告、支付、云存档或社交功能。
