## 2. 微信小游戏首包限制

| 项 | 限制 |
|---|---|
| 首包（主包） | ≤ 4MB |
| 总包（含远程资源） | ≤ 200MB |
| 单个分包 | ≤ 4MB |
| 分包数量 | 主包 + 最多 20 个分包 |
| 远程资源 | 需在 mp.weixin.qq.com 后台 → 开发管理 → 服务器域名 → downloadFile 合法域名 |

## 3. 分包策略

### 3.1 主包（首包，≤ 4MB）

**必含**：
- `main-*.js` (384KB)
- `main-*.css` (~100KB)
- `game.json` + `project.config.wx.json` (Windows 平台配置)
- **关键 3 张图**（必要最低限度）：
  - `title_keyart.webp` (128KB) — 标题页主视觉
  - `avatar_*.webp` (76KB) — 头像（首屏展示用）
  - `bg_*.webp` 一张（用作加载缓冲占位） ≈ 150KB

**总计**：约 838KB + 引擎壳 ≈ 1.2MB。**安全余量 2.8MB**。

⚠️ 注意：当前主包只放 JS+CSS+3 张图。要进 Vite 构建时通过 `assetsInlineLimit` 和 `build.rollupOptions.output.assetFileNames` 控制。

- 序章 1-10 合并为 `pkg-chapter-s` (~26MB)
- 第一章 1-8 合并为 `pkg-chapter-c` (~1.2MB)
- `pkg-stages` (战斗、结算) 单独
- `pkg-audio` 单独

→ 4 个分包 + 主包。

### 3.3 远程资源策略

**当分包还不够时**（按上面合并后可能仍超），可以考虑：

- **音频**（BGM + 大量配音）放在远程 CDN：
  - 微信小游戏允许远程资源
  - 需在 `mp.weixin.qq.com` 后台配置 `downloadFile` 合法域名
  - 当前版本用本地无服务器，可以暂时挂 `https://公网CDN/`
- **超分包的剩余素材**也走远程

## 4. Vite 构建支持

### 4.1 当前 `vite.config.minigame.ts` 调整

```typescript
// vite.config.minigame.ts（调整后）
export default defineConfig({
  plugins: [react()],
  resolve: { alias: [...] },
  build: {
    outDir: 'dist-minigame',
    emptyOutDir: true,
    rollupOptions: {
      input: {
        main: 'src/main.minigame.tsx',
      },
      output: {
        // 关键：把图片、音频、battle 等按类型分包
        assetFileNames: (assetInfo) => {
          const name = assetInfo.name ?? ''
          if (name.startsWith('main-')) return 'assets/[name][extname]'
          if (name.endsWith('.webp') || name.endsWith('.png')) {
            // 战斗 sprite 单独分包
            if (name.includes('battle/')) return 'pkg-stages/battle/[name][extname]'
            // 章节背景按 stage 命名分包
            const m = name.match(/^bg_(.+?)\.(webp|png)$/)
            if (m) return `pkg-chapter-${m[1]}/[name][extname]`
          }
          if (name.endsWith('.mp3')) return 'pkg-audio/[name][extname]'
          return 'assets/[name][extname]'
        },
        chunkFileNames: 'assets/[name][extname]',
      },
    },
    assetsInlineLimit: 4096,
  },
  define: {
    'process.env.MINIGAME_BUILD': '"true"',
    'process.env.PLATFORM_NAME': '"wechat"',
  },
})
```

### 4.2 微信小游戏需要的 `game.json` subpackages 字段

`game.json` 当前没声明 `subpackages`。需要补：

```json
{
  "subpackages": [
    { "name": "pkg-chapter-s", "root": "pkg-chapter-s" },
    { "name": "pkg-chapter-c", "root": "pkg-chapter-c" },
    { "name": "pkg-stages", "root": "pkg-stages" },
    { "name": "pkg-audio", "root": "pkg-audio" }
  ]
}
```

**注意**：微信小游戏分包的代码根路径必须以分包名开头，资源路径以 `pkg-xxx/...` 引用。

## 5. 立即可执行的素材压缩

### 5.1 大图压缩（首期必做）

| 文件 | 当前 | 目标 | 工具 |
|---|---|---|---|
| `assets/battle/hero_mengjia_idle_v1.png` | 2.4MB | < 200KB | sharp / pngquant / cwebp |
| `bgm/farm.mp3` | 4.6MB | < 2MB | ffmpeg 重新编码 96kbps |
| `bgm/court.mp3` | 3.9MB | < 2MB | ffmpeg 重新编码 96kbps |
| `bgm/ambush.mp3` | 3.7MB | < 2MB | ffmpeg 重新编码 96kbps |

| `assets/bg_tingwei.png` | 436KB | < 200KB | sharp → WebP |
| `assets/portrait_xiaoman.png` | 388KB | < 200KB | sharp → WebP |

**预估节省**：约 13MB。

### 5.2 配音文件压缩

143 个 mp3，总共 13MB。平均每个 90KB。**不需要全部压缩**，可以：

- 保留 128kbps（当前估计值）
- 如果确需缩小，改 96kbps（听感差异不大）
- **预估节省**：约 4MB
