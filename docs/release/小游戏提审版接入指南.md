# 《秦灭六国》小游戏提审版接入指南

> 用途：把当前 Web Demo 接入到平台适配器，生成可上传到微信/抖音的可执行包。
> 原则：保留现有 `src/game/*.ts` 业务逻辑，只在 Vite alias 层切换实现。
> 阅读对象：实施迁移的开发者。

---

## 当前状态

- 项目当前是 **React 19 + Vite 7 浏览器 Web Demo**
- 现有 `src/game/save.ts` 用 `localStorage`
- 现有 `src/game/audio.ts` 用 `new Audio()`
- 微信/抖音小游戏**没有** `localStorage`、**没有** `new Audio()`

---

## 三步接入法

### 第 1 步：构建配置（已完成）

`vite.config.minigame.ts` 和 `vite.config.minigame.douyin.ts` 已配置 alias：

```typescript
// vite.config.minigame.ts
resolve: {
  alias: {
    '@': '/src',
    '@/platform': '/src/platform/index.wx',  // 指向微信版
  },
}
```

提审版构建：

```bash
# 微信版
npm run build:minigame

# 抖音版
npm run build:minigame:douyin
```

`vite.config.minigame.ts` 文件位于项目根目录：[`vite.config.minigame.ts`](file:///Users/zhuangxiji/Desktop/CC/qin-mie-liu-guo-demo/vite.config.minigame.ts)

### 第 2 步：现有代码改造（**待你决策**）

**当前 `src/game/save.ts` 直接使用 `localStorage`**：

```typescript
// src/game/save.ts 第 271 行
const raw = localStorage.getItem(KEY_PREFIX + slot)
```

**当前 `src/game/audio.ts` 直接使用 `new Audio()`**：

```typescript
// src/game/audio.ts 第 48 行
const el = new Audio(url(name))
```

**两种改造方案**：

#### 方案 A：直接修改现有文件（推荐）

在 `src/game/save.ts` 顶部添加：

```typescript
import { storage } from '../platform'
```

把所有 `localStorage.getItem/setItem/removeItem` 替换为 `storage.get/set/remove`。

在 `src/game/audio.ts` 顶部添加：

```typescript
import { createAudio, unlockAudio as platformUnlockAudio } from '../platform'
```

把所有 `new Audio()` 替换为 `createAudio()`。

⚠️ **风险**：现有浏览器版验证脚本可能因适配器兼容性失败。

#### 方案 B：通过 Vite alias 重写（更安全）

创建 `src/game/save.adapter.ts`（适配器版），内容用 `storage` 替代 `localStorage`。
创建 `src/game/audio.adapter.ts`（适配器版），内容用 `createAudio` 替代 `new Audio`。

在 `vite.config.minigame.ts` 中添加：

```typescript
alias: {
  '@/platform': '/src/platform/index.wx',
  '/src/game/save.ts': '/src/game/save.adapter.ts',
  '/src/game/audio.ts': '/src/game/audio.adapter.ts',
}
```

✅ **优点**：浏览器版零修改，提审版自动切换。

### 第 3 步：业务代码（用户代码）

这部分仍然是 DOM/React 组件，**无法直接在小游戏运行**。

需要：
- 把 `src/sections/StoryScene.tsx` 改写为 Canvas 渲染

- 把 `src/sections/TitleScreen.tsx` 改写为 Canvas 渲染
- 把 `src/ui/C7ChoicePanel.tsx` 等改写为 Canvas 组件

## 关键代码段对比

### 浏览器版 vs 微信版

```typescript
// 浏览器版（src/platform/storage.web.ts）
export const storage = {
  get(key: string): string | null {
    return localStorage.getItem(PREFIX + key)
  },
  // ...
}

// 微信版（src/platform/storage.wx.ts）
export const storage = {
  get(key: string): string | null {
    const value = wx.getStorageSync(PREFIX + key)
    return value === undefined ? null : value
  },
  // ...
}
```

调用方代码（业务逻辑）**完全一致**：

```typescript
// 浏览器版、小游戏版、抖音版通用
import { storage } from '../platform'

const data = storage.get('save:0')
storage.set('save:1', JSON.stringify({...}))
```

### 音频对比

```typescript
// 浏览器版
const el = new Audio(src)
el.play()

// 微信版
const audio = wx.createInnerAudioContext()
audio.src = src
audio.play()

// 统一版本（推荐）
import { createAudio } from '../platform'
const el = createAudio(src, { autoplay: true })
```
