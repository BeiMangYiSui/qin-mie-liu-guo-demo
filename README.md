# 秦灭六国 · 玩法 Demo

> 历史已定，抉择在你。

一款纯浏览器运行的叙事 RPG，无需下载，打开即玩。

## 试玩

🎮 **https://shixiaofei-sunny.github.io/qin-mie-liu-guo-demo/**

## 简介

扮演秦军秘密行动头领北芒，与医者小满、剑士青翎共历秦灭六国前夜。

- 无等级、无装备、无刷怪
- 多分支剧情，你的选择锁定后续选项
- 三档结算评级 + 史乘系统
- 序章《郑地伏杀》+ 第一章《新郑覆旗》，约 70 分钟体验

## 技术栈

React 19 + TypeScript + Vite 7 + Tailwind CSS

## 本地运行

```bash
npm ci
npm run dev
```
